# Gemmi — Персональный ИИ-ассистент для Kubuntu

**Gemmi (Джемини)** — это автономная экосистема персонального ИИ-ассистента для ОС Kubuntu, реализующая принцип «ИИ как shell-оболочка» (перевод команд на естественном языке в системные действия без жестких скриптов).

---

## 📌 Архитектура и ключевые особенности

1. **Принцип «ИИ как shell-оболочка»**:
   - Перевод естественного языка в системные команды Bash/D-Bus.
   - Разделение на «Режим инструмента» (выполнение по команде) и «Режим партнера» (диалог).

2. **Двухуровневая память**:
   - Сессионный контекстный буфер (история текущего диалога).
   - Долгосрочное состояние (`active_state.json` и `ContextManager`).

3. **Каскадный обход моделей (LLM Cascade)**:
   - Прямое обращение к Gemini REST API без сторонних SDK.
   - Автоматический бесшумный перебор приоритетного списка доступных моделей (`MODELS_CASCADE` в `modules/llm_client.py`), гарантирующий отказоустойчивость при отсутствии отдельных версий API.

4. **Контур безопасности**:
   - `rm` подменяется перемещением в корзину (с запретом на её очистку).
   - Автоматическое создание `.bak` копий редактируемых файлов.

5. **Системный контекст**:
   - Модуль мгновенных снимков окружения (`instant_snapshot.py`).
   - Интеграция с systemd, D-Bus и Syncthing для кросс-девайсной синхронизации.

---

## 🛠 Технологический стек

* **Язык**: Python 3.12+
* **Графический интерфейс**: PyQt6 / Streamlit
* **API ИИ**: Gemini REST API (v1beta)
* **Интеграция с ОС**: Linux (Kubuntu), systemd, D-Bus, Bash
* **Синхронизация**: Syncthing

---

## 📁 Структура проекта

* `run_widget.py` — Главная точка запуска графического виджета ассистента.
* `modules/llm_client.py` — Клиент работы с Gemini API с поддержкой каскада моделей (`MODELS_CASCADE`).
* `modules/context_manager.py` — Управление памятью, контекстом диалога и сохраненными состояниями.
* `modules/instant_snapshot.py` — Сбор снимка системного окружения.
